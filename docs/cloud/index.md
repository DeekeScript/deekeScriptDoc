# DeekeScript Cloud

> 一次编写，任意设备执行。

## 什么是 DeekeScript Cloud？

**DeekeScript Cloud** 是 DeekeScript 官方推出的 **Android 多设备脚本执行平台**。

开发者只需要编写一次 **DeekeScript**，即可通过 Web 将脚本分发到任意在线 Android 设备执行。平台负责设备连接、任务调度、脚本管理、实时日志以及运行监控，让自动化脚本从 **单机运行** 升级为 **多设备协同执行**。

整个执行过程无需 ADB、无需 USB、无需局域网，只要设备联网，即可随时随地接入平台。

---

## 为什么选择 DeekeScript Cloud？

传统 Android 自动化通常依赖：

- USB + ADB 调试
- 本地电脑运行脚本
- 单机管理设备
- 手动维护脚本版本
- 无法远程管理设备

当设备数量从 **1 台** 增长到 **10 台、100 台甚至更多** 时，传统方案的管理成本将迅速增加。

DeekeScript Cloud 将这些能力统一交给平台管理：

- 🌐 一个平台管理所有 Android 设备
- 📜 一个脚本即可分发到多台设备
- 🚀 一个任务即可批量执行
- 📊 一个页面查看所有运行状态
- 👥 多人协作，共享设备资源

真正实现 **自动化规模化执行**。

## 🔗 无需 ADB，设备永久在线

DeekeScript Cloud 基于 **WebSocket 长连接** 构建设备通信网络。

相比传统 ADB：

- ✅ 无需 USB 连接
- ✅ 无需安装驱动
- ✅ 无需配置环境变量
- ✅ 支持公网远程接入
- ✅ 自动断线重连
- ✅ Web 即可统一管理

设备安装 **DeekeScript Agent** 后即可加入平台，实现长期在线、远程执行。

# 平台架构

```text
             Web Console
                  │
       ┌──────────┴──────────┐
       │  DeekeScript Cloud  │
       └──────────┬──────────┘
                  │
          Task Dispatcher
                  │
      ┌───────────┼───────────┐
      │           │           │
    Agent       Agent       Agent
      │           │           │
 Android      Android     Android
```

开发者负责编写脚本。

Cloud 负责调度。

Agent 负责执行。

三者共同组成完整的 Android 自动化执行体系。

# 快速开始

平台正式发布后，仅需三步即可开始使用：

1. 注册 **DeekeScript Cloud** 开发者账号。
2. 在 Android 手机上安装 **DeekeScript Agent** 并绑定设备。
3. 上传或编写 DeekeScript，选择设备，一键执行。
